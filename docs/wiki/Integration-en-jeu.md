# Intégration en jeu

| Option | Possible ? | Détail |
|---|---|---|
| Ouvrir le site en jeu | ✅ | Navigateur de l'overlay Steam (`Maj` + `Tab`) |
| Mod Steam Workshop synchronisé | ❌ | Les mods Workshop sont des données (FCS) sans accès réseau ; les DLL y sont refusées. AnarchyKenshi lui-même a été retiré du Workshop. |
| Plugin DLL (RE_Kenshi + KenshiLib) | ⚠️ | Techniquement possible (HTTP + fenêtre en jeu), distribué via Nexus/GitHub. Nécessite l'accord / une API de l'auteur d'AnarchyKenshi (code fermé). |
| Kenshi-Online (open source) | ⚠️ | Serveur dédié open source : intégration côté serveur envisageable si on change de mod multijoueur. |

**Prochaine action** : contacter l'auteur d'AnarchyKenshi (Anarchy / AnarchyMK2) pour une API serveur (liste des joueurs, factions).

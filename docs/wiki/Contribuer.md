# Contribuer

1. **Fork** le dépôt.
2. Lance le site en local : `python3 -m http.server 8000`.
3. Fais tes changements (villes, traductions, code).
4. Ouvre une **Pull Request**.

Idées bienvenues : coordonnées des villes, traductions, icônes de factions.
